# quantitative-portfolio-research-and-optimization-platform

## Objective

The project aims to analyze individual stocks and portfolios using:

- Real market data
- Fundamental analysis
- Technical analysis
- Statistical analysis
- Risk modelling
- Portfolio optimization
- Monte Carlo simulation
- Backtesting

## Planned Features

- Live market data
- Portfolio tracking
- Stock analytics
- Risk metrics
- Correlation analysis
- Efficient frontier
- Maximum Sharpe portfolio
- Minimum volatility portfolio
- Risk parity
- Black-Litterman optimization
- Monte Carlo simulation
- Backtesting

## Technology

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- SciPy
- Statsmodels
- Scikit-learn
- CVXPY
- PyPortfolioOpt

## Status

Currently under development.
