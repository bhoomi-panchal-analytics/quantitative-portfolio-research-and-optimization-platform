# quantitative-portfolio-research-and-optimization-platform

## Objective

The project aims to analyze individual stocks and portfolios using:

- Real market data
- Fundamental analysis
- Technical analysis
- Statistical analysis
- Risk modelling
- Portfolio optimization
- Monte Carlo simulation
- Backtesting

## Planned Features

- Live market data
- Portfolio tracking
- Stock analytics
- Risk metrics
- Correlation analysis
- Efficient frontier
- Maximum Sharpe portfolio
- Minimum volatility portfolio
- Risk parity
- Black-Litterman optimization
- Monte Carlo simulation
- Backtesting

Data warning

The prototype uses yfinance. It is useful for research but is not a guaranteed
zero-latency NSE/BSE feed. Replace the price-data functions with a licensed
broker or exchange data provider before using the application for live trading.
